# 보리런 디자인 초안 v0.1

## 방향

경쟁의 긴장감보다 동네 러닝 클럽의 소속감을 앞세운다. 보리의 금빛, 짙은 초록, 크림색으로 수확·성장·러닝 후의 편안함을 표현한다. 맥주는 출발점인 이야기로 남기고, 앱을 음주 권유나 주류 구매 경험으로 만들지 않는다.

- 이름: **보리런 / BARLEY RUN** (작업용 브랜드)
- 핵심 문구: **우리 동네의 한 걸음이, 좋은 일로.**
- 영문 보조 문구: **Run together. Grow together.**
- 경쟁 단위: 개인 기록을 지역 팀의 누적 거리로 연결
- 시각적 보상: 보리 이삭, 따뜻한 햇빛, 러너 일러스트, 기부 감사 이름

## 디자인 토큰

시스템 한글 글꼴을 사용해 별도 폰트 다운로드 없이 실행한다. 거리와 페이스는 tabular numerals로 자리 흔들림을 줄인다. 네이티브 safe area, 접근성 버튼·탭 이름, 선택 상태, 위치 오류 알림을 지원한다. 정식 버전에서는 스크린리더·큰 글자·색 대비를 실기기에서 추가 검토한다.

## 화면 흐름

1. **홈**: 시즌과 첫 러닝 CTA → 나의 거리/팀 순위/기부 예시 → 지역 리그 → 수혜 활동 소개.
2. **지역 선택**: 지역 검색 → 참여 확정. 시즌 동안 고정된다는 설명을 확정 전에 제공.
3. **토너먼트**: 누적 거리 순위, MY TEAM, 종료까지 남은 날, 대회 규칙.
4. **러닝**: 거리 중심 타이포, 시간·페이스, GPS 또는 명시된 데모, 일시정지·재개·종료.
5. **기부**: 후보 프로젝트, 수익·운영·기부 배분 예시, 이름 공개 안내, 아직 비어 있는 전달 내역.
6. **내 기록**: 로컬 닉네임·선택 동의, 전체 거리, 러닝 히스토리, 확인 후 데이터 삭제.

모바일은 하단 5탭, 데스크톱은 녹색 사이드바와 2열 카드로 구성한다. 지도는 비용·개인정보·외부 의존성을 추가하지 않도록 코스 일러스트로 표시하며 실제 위치로 오인하지 않게 설명한다.

## 수정 위치

`App.tsx`의 `C`와 `StyleSheet`에서 색·간격·타이포를 수정한다. `src/components/Art.tsx`는 로고·일러스트의 원본이다. 이미지 스냅샷은 브라우저 테스트가 `docs/design/`에 저장한다. Figma 원본 파일은 생성하지 않았다.
